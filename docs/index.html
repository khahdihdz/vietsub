Cài đặt từ bên ngoài Web Store

Tải bản .crx ở nút phía trên. Nếu Chrome/Brave cho phép cài CRX ngoài Web Store, mở trang Extensions và kéo file vào đó.

  1. Mở chrome://extensions hoặc brave://extensions.
  2. Bật Developer mode.
  3. Kéo ai-vietsub-extension.crx vào trang Extensions.
  4. Nếu trình duyệt chặn CRX, dùng phương án dự phòng: tải mã nguồn từ GitHub → giải nén → chọn Load unpacked và chọn thư mục chứa manifest.json.

Cách sử dụng

1. Cấu hình

Nhập OpenRouter API key và chọn model dịch/STT.

2. Phát video

Bấm “✨ Tạo phụ đề tự động” để bắt đầu nhận dạng.

3. Xem phụ đề

Phụ đề tiếng Việt xuất hiện trực tiếp trên video.

4. Thuyết minh

Bật tính năng dubbing để đọc phụ đề tiếng Việt.

Riêng tư
